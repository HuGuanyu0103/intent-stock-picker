# AI 使用与验证记录

## 一、使用的 AI 工具

1. **AI Coding 助手（Claude Code）**：参与全部代码编写、接口调试、前端实现与文档撰写。
2. **产品内 AI（意图层）**：当前版本为**确定性规则解析器**（`core/parser.py` 的指标注册表 + 模糊词翻译词典 + SSE 解读流模板），模块内预留了 LLM 增强适配位（`LLM_API_KEY` 接入后可替换为大模型语义解析，输出仍受同一份 JSON Schema 与指标白名单约束）。

刻意选择规则版作为黑客松交付：翻译口径可解释、行为可复现、换模型不变形，这本身就是产品立场（"翻译规则是产品资产，不是模型临场发挥"）。

## 二、AI 参与的环节 vs 确定性环节

| 环节 | 承担方 |
|---|---|
| 模糊意图→条件 JSON、解读流叙事、澄清/口误提示 | AI（规则实现，LLM 可替换） |
| 指标计算、阈值判定、入选/排除/缺失分组、冲突检测、试算计数、贴合度、diff | 确定性引擎（pandas/纯 Python），AI 不可触碰 |
| 数据获取 | 扶摇 API + 串行限速客户端 |
| 阈值最终裁决、条件增删改 | 用户 |
| 代码与方案设计 | 人 + AI Coding，人做全部设计决策 |

## 三、候选人修正 AI 的错误/不合理结果（实测记录）

| # | AI/初版方案 | 问题 | 修正方式 | 是否进入回归 |
|---|---|---|---|---|
| 1 | 把"便宜"映射为"绝对股价低" | 低股价≠低估值，语义错误且会筛出局面值垃圾股 | 词典固定映射为 PE-TTM 分位；评测用例锁死 | ✅ tests: "便宜映射为估值分位而非绝对股价" |
| 2 | 同一分句"剔除 ST 和上市不满一年的"只识别 ST | 分词+提前 break 导致第二条红线丢失 | 排除匹配不 break；再叠加整句兜底扫描 | ✅ tests: "新股红线被整句兜底识别" |
| 3 | "低估值的不要"被静默翻译成正向估值条件 | 同句矛盾（疑似口误），静默执行危险 | 检测正向短语与排除词同句→挂起并要求澄清 | ✅ tests: "口误表达不产出正向估值条件" |

| 10 | ST/新股布尔红线卡上渲染了数值输入框 | 卡片模板未区分数值型/布尔型 | 布尔型只渲染三档/红线标识，不渲染输入框 | ✔ 无头浏览器回归 |
| 11 | 追加/修改条件后，所有留存股票都被打"新增"标记 | diff 集合算成了新结果全集而非差集 | 新增标记改为 newSet−oldSet，且改条件重跑同样出 diff（改严掉出 7、改松新增 7 实测正确） | ✔ DOM 断言：新增 0/新增 7 |
| 12 | "剔除 ST 和上市不满一年的"被空格切碎后，解读流误挂起"剔除""和上市不满一年的"两条 | 分词产生语气碎片 + 分句缺排除动词 | 加停用碎片表；分句无排除动词但整句处于排除语境时红线仍生效 | ✔ 挂起数=0 回归 |
| 13 | 移动端证据表溢出、输入框可能触发 iOS 缩放 | 未做响应式 | 媒体查询 + 证据表横向滚动 + 输入框 16px | ✔ 420px 视口走查 |
| 14 | **用户实测发现**："不要 ST"在入选股证据表里显示"要求==是、✘不满足"，被读成"系统在选 ST" | 引擎内部分组正确（ST 进排除组），但排除条件的双重否定内部表示（is_st==True 触发排除）被原样投影给用户 | 投影层翻转：排除条件展示翻回正向安全语义（op ==→≠、pass↔fail，unknown 不变），分组仍按内部判定；红线卡显示"该标志必须为否"；新增 2 条锁定断言 | ✔ 合成 ST 股用例 + 浏览器走查 |
| 15 | 复盘发现"不稳定的股票""不便宜的"被子串匹配反向翻译成正向条件（比 #14 更隐蔽） | 关键词包含匹配无视否定词；且反义意图有的可翻转、有的反直觉 | 否定窗口检测 + 预设标注 negation=flip/ask：「不稳定」翻成高波动条件、「不便宜/没增长」挂起；反向条件独立 id 可与正向共存；5 条否定用例进回归 | ✔ 5 条否定断言 |

| 17 | 贴合度排序用 `(值−阈值)/|阈值|`，阈值为 0 时退化为除 1，利润增速 margin 达几十、分位条件仅 0.x，跨指标不可比 | 不同量纲直接相除 | 全部数值条件统一映射到池内横截面分位，阈值也过池内 CDF，margin ∈ [-1,1] 后再取最短板 | ✔ 排序合理性人工核对 |
| 18 | 数据时点写死 2026-09-23、行业条件长期挂起、预热失败无感知 | MVP 赶工遗留 | as_of 改由 K 线最后交易日推断；预热 710 个行业/概念成分（零失败）支持真实 in/not-in 条件；矩阵产出批次健康报告（缺失率>15% 红色告警） | ✔ 行业 300/300 覆盖、健康接口实测 |
