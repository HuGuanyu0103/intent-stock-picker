## 三、评审建议体验路径（约 3 分钟）

1. 打开公网地址，点"示例：标准三连"，观看流式解读（AI 声明如何理解每句话）；
2. 条件卡上看**口径 + 专家值理由 + 全池试算计数**，把波动率档位在严格/宽松间切换，观察命中数变化；
3. 运行 → 展开入选第一名看逐条件证据；切"差一点"看卡点字段（如"回撤 17.7%，要求 ≤15%"）；切"数据不足"看亏损公司如何因 PE 无意义被隔离而非误判；
4. 改条件重跑或在结果框输入"成交活跃"追加条件，看结果集 **diff（新增/掉出计数与绿标）**；
5. 输入"推荐几个下周涨停的黑马"，看合规拦截；输入"便宜的好公司，剔除银行板块"，看无法量化表达被诚实挂起而非硬编。

## 四、本地运行（无 Key 也可完整复现）

```bash
cd 02_源代码
pip install -r requirements.txt
python3 app.py          # 打开 http://127.0.0.1:8080
python3 tests/test_engine.py   # 17 项离线断言
```

- 不配置 `FUYAO_API_KEY`：使用包内 `data/matrix.json`（2026-09-23 沪深 300 真实预热快照，300 只），界面标注样例模式；
- 配置 Key（扶摇金融数据 API，`.env.example` 有说明）：运行 `python3 scripts/preheat.py` 重新预热当日全池（约 4 分钟，5 req/s 限速），再 `python3 core/metrics.py` 重建矩阵；
- 行为埋点写入 `data/events.jsonl`，无第三方、无用户身份。

## 五、数据与合规说明

- 数据源：同花顺扶摇金融数据 API（沪深300 成分、估值快照、财务指标、日 K 线），数据时点 2026-09-23 收盘；
- 全部关键数字可回到字段值（实际值/阈值/口径/时点在证据表中展示）；数据缺失、接口失败一律落"不可判定/风险待核实"隔离组，不静默产出正常结论；
- 产品不输出涨跌预测、收益承诺、目标价或买卖建议；"入选"仅表示"符合用户设定的条件"。

## 六、已知限制（诚实声明）

- 样本池仅沪深 300；8 个预注册指标；条件仅 AND + 单指标谓词（含行业集合条件暂为挂起态）；
- 扶摇估值接口仅提供最新快照，故分位为池内横截面口径，自身历史分位未做；
- 公网预览为黑客松 Worker 临时环境（数据冻结在 2026-09-23），长期使用可按 README 自行部署；
- 意图解析当前为**确定性规则版**（行为可复现、口径可审计），LLM 增强位已预留；是否上 LLM 由评测数据决定（见评测体系 v1.3 节）。
