# 测试说明

## 运行方式

```bash
python3 tests/test_engine.py     # 17 项离线断言，零依赖（仅需本仓库 core 模块）
```

## 覆盖矩阵

### 1. 主链路（自然语言→条件→筛选）

| 输入 | 预期 |
|---|---|
| "经营改善、估值合理、走势相对稳定，剔除 ST 和上市不满一年的" | 7 条条件（4 正向意图拆 5 卡 + 2 排除红线）；标准真实数据下入选 32 / 差一点 22 / 数据不足 21 |
| "低估值、业绩增长、成交活跃，不要ST" | 含成交额条件；全部指标在白名单内 |
| 逐卡试算 | 运行前显示每卡满足/剔除数（如 192/300、52/300） |
| 条件三档切换 | 宽松/适中/严格改变阈值，试算计数与结果实时变化 |
| 追加条件 | "成交活跃"合并后入选 32→19，diff 提示新入/掉出 |

### 2. 数据/接口异常

| 场景 | 行为 |
|---|---|
| 财务指标未披露（字段 null） | 该条判定 unknown → 股票进"数据不足"组，明示缺失字段；不进入选也不当作淘汰 |
| 亏损公司 PE 为负 | PE 不参与分位，该条 unknown → 不可判定（21 只实测落组） |
| 接口超时/500 | 客户端指数退避重试 3 次；仍失败则该数据源缺失，走 unknown 路径而非编造 |
| 未配置 API Key | 服务以样例/预热缓存模式启动，界面顶部全程标注模式 |
| 当日快照缺行 | 判定为停牌 |

### 3. 合规边界

| 输入 | 预期 |
|---|---|
| "推荐下周涨停的黑马""买入""必涨" | 意图闸门拦截，不出条件不出结果，引导回条件表达 |
| 结果文案 | 全站无买卖点/目标价/收益承诺；"入选"表述为"符合你设定的条件" |
| 专家值卡片 | 标注"专家值"来源与"不构成投资建议" |

### 4. 极端/刁难怪问

| 输入 | 预期 |
|---|---|
| "便宜的好公司，剔除银行板块" | 估值正常成卡；行业类进"未理解"灰卡并说明原因，不硬编 |
| "低估值的不要"（口误） | 同句矛盾挂起澄清，不默默产出正向条件 |
| 同指标互斥阈值（PE ≤0.3 且 ≥0.8） | 硬冲突，运行按钮禁用并定位条件 |
| 两条以上条件不符 | 不进任何展示组，在页签旁给"多条不符已隐去 N 只"计数，不假装看过全市场 |

## 可追溯性

每只入选/差一点/排除/不可判定股票均可展开逐条件表：指标名、实际值（带单位）、运算符与阈值、三值判定结果；卡片口径悬停可见数据时点（2026-09-23 收盘预热）与扶摇来源接口。
