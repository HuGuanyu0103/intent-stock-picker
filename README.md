# 条件协作台 · 自然语言智能选股与策略解释器

把投资者的模糊表达（"经营改善、估值合理、走势相对稳定"）翻译成**可检查、可修改、可执行、可追溯**的数据条件，由确定性引擎在真实数据上筛选，并逐只解释**为何入选、为何被排除、数据缺失在哪**。

与同花顺问财这类黑箱式自然语言选股的差异：本产品输出的不是一个股票列表，而是一份用户看得懂、改得动的**条件合同**——每个阈值有口径、有专家预设三档、有全池试算计数；改一条条件，结果集增量实时可见。

## 产品选择与 AI 的角色

核心立场：**金融场景下 LLM 不直接分析裸数据、不决定选股结果**。四方职责边界：

| 角色 | 只允许做 | 明确不做 |
|---|---|---|
| AI（意图层） | 模糊表达→受 Schema 约束的条件 JSON、解读流叙事、澄清 | 不取数、不算指标、不决定入选、不发明白名单之外的指标 |
| 确定性引擎 | 指标计算、三值判定、四分组、冲突检测、试算计数、贴合度、diff | 不产生自然语言结论 |
| 金融数据工具（扶摇 API） | 提供带时点与单位的原始字段 | — |
| 用户 | 检查/修改/删除条件、决定执行、追加条件 | — |

前端展示的每一个数字都来自引擎判定结果对象，AI 文案不携带任何自造数字。

## 数据来源与口径

| 数据 | 扶摇接口 | 用途 |
|---|---|---|
| 沪深300 成分 | `/a-share-index/constituents/ths-stock-list` | 样本池 |
| 估值快照 | `/a-share/valuations/snapshot` | PE-TTM/PB（仅最新快照） |
| 财务指标 | `/a-share/financials/indicators` | 2026 中报归母净利/营收同比、ROE |
| 行情快照/日K | `/a-share/prices/snapshot`、`/historical` | 停牌、成交额、波动率、回撤 |
| 代码表 | `/meta/tickers/list` | 名称（ST 识别） |

指标口径（全部为产品预注册，非 AI 临场解释）：

- **经营改善**：2026 中报归母净利润同比 > 0 **且**营业收入同比 > 0；
- **估值合理（专家默认）**：PE-TTM 为正且处沪深300 内 ≤50% 分位（横截面口径，宽松 70%/严格 30%）；亏损公司 PE 无意义→不可判定；
- **走势稳定**：近 60 日年化波动率池内分位 ≤40%，且近 120 日最大回撤 ≤15%；
- **成交活跃**：近 20 日日均成交额 ≥5 亿（宽松 2 亿/严格 10 亿）；
- **排除红线**：ST/*ST（名称识别）、新股。

## 关键机制

- **三值判定**：pass / fail / unknown。字段缺失、未披露、接口失败一律 unknown，永不混入入选或淘汰。
- **结果四分组**：入选（按"最短板贴合度"透明排序，非黑箱综合评分）/ 差一点（恰好卡 1 条，显示卡点字段与差距）/ 已排除（触发用户红线，默认折叠）/ 不可判定（数据不足 + 风险待核实）。
- **排除项查无数据**：硬红线无法核实时进"风险待核实"隔离组，不替用户做疑罪从有/从无的判断。
- **逐卡试算**：运行前每张卡显示"X/300 只满足/将剔除 N 只"，条件过严过松当场现形。
- **硬冲突拦截**：同指标阈值区间无交集时阻止运行。
- **口误识别**："低估值的不要"这类同句矛盾不默默执行，挂起待澄清。
- **二次筛选**：结果页追加自然语言条件，合并同一条件模型重跑，结果集 diff 高亮新入/掉出。
- **合规**：不输出涨跌预测、买卖建议、目标价；荐股类意图直接拦截并引导。

## 技术栈

Flask + 原生单页（无构建步骤）+ pandas 指标矩阵；SSE 流式解读；预热数据落 JSON，执行筛选为本地秒级运算。

```
core/fuyao.py     扶摇客户端（限速/退避重试）
core/metrics.py   指标矩阵（全部确定性计算）
core/parser.py    指标注册表 + 模糊词翻译词典 + 确定性意图解析（LLM 增强适配位）
core/engine.py    三值四分组/冲突/试算/贴合度/diff
app.py            API + SSE
scripts/preheat.py  每日预热
tests/test_engine.py  离线测试（17 项，python3 tests/test_engine.py）
```

## 已知边界与未做事项

- 样本池仅沪深 300；指标仅 8 个预注册口径；条件仅 AND + 单指标谓词，不支持 OR/嵌套/跨期表达式。
- 扶摇估值接口**只提供最新快照**，故历史分位（自身近 3 年）未做；当前为池内横截面分位。
- 扶摇代码表 `list_date` 实测返回为空，"新股"改用日 K 根数近似（400 自然日窗口内 <130 根 ≈ 上市 6 个月内）；沪深300 成分实际命中为 0。
- 无股本字段，未提供市值/换手率；行业/概念集合条件暂进"未理解"挂起（行业映射需额外 320 次预热调用）。
- 未做：回测、方案保存、监控任务、多轮语义指代、大模型接入（解析器预留增强位，规则版行为完全可复现）。
- 数据为 2026-09-23 盘后预热快照，非实时行情。
